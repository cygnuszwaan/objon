# Export-write audit log

Tracks which scripts have been checked against the level-editor rule in objon.md ("Level editor seams"): **runtime code never writes an authored export**. Update this file whenever you audit or change an object, and delete it when the final pass is done and nothing is open.

**Method.** `audit_export_writes.py` (next to this file; run from the project root, `--json out.json` for machine output) is a regex scan for assignments and mutating calls on a script's own exports outside the export's setter, plus writes to any exported name through another reference. It covers all scripts. Every hit was then read by hand. **Limits:** it does not see writes through `set()`, exported Resources mutated in place, or an exported array mutated through an alias, and it reports built-in node properties that share a name with an export. A clean scan is not proof.

**Severity.** A violation matters only if the editor plays in place. If a play-test always runs a fresh instance of the saved level (as the reload path already does), the rule is a preference and these are low priority. The pattern to copy is `WaterBasin` (`initial_fill_depth_below_surface` authored, `fill_volume` runtime).
